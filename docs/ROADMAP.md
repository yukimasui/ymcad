# ロードマップ

本プロトタイプの **非スコープ** 項目を、将来の拡張候補として記録しておく。
以下はいずれも今回は実装しない。

## 作図・編集

- **OFFSET** — 自己交差の処理が別問題として重い
- **TRIM / EXTEND** — 交点計算とトポロジ管理が必要
- **FILLET / CHAMFER** — 同上
- **ハッチング** — 境界検出とパターン生成
- **寸法記入** — 寸法スタイル、連動寸法
- **ブロック、外部参照**
- **文字要素** — IME の動作検証（Phase 0）は済んでいるが、テキストエンティティ自体は未実装

## 3D

- 3D 機能全般

## 入出力

- **DWG 形式** — 仕様が非公開のため
- **印刷 / PDF 出力**
- DXF の R12 より新しいバージョン（R2000 以降）
- DXF の SPLINE / ELLIPSE / HATCH などの追加エンティティ

## プラットフォーム

- **Windows / macOS 対応**
- **Web / wasm ビルド** — ただし `cad-core` を UI 非依存に保っているため、
  ビューアを載せる余地は残してある

## その他の候補

- 極トラッキング / オブジェクトスナップトラッキング
- ダイナミック入力（カーソル近傍での寸法入力）
- グリップ編集
- 図面テンプレート
- 印刷レイアウト（ペーパー空間）
