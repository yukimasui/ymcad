# ロードマップ

本プロトタイプの **非スコープ** 項目を、将来の拡張候補として記録しておく。
以下はいずれも今回は実装しない。

## 作図・編集

- **OFFSET** — 自己交差の処理が別問題として重い
  （`XLINE` の `O` オプションによる作図線のオフセットのみ実装済み）
- ~~**TRIM / EXTEND**~~ — Issue #7 段階 3 で実装。**線分のみ**。
  ポリラインの部分トリムは頂点列の再構成が必要なので残課題（ADR-0023）
- ~~**FILLET / CHAMFER**~~ — Issue #7 段階 3 で実装。**線分同士のみ**。
  円・円弧を含む角、ポリラインの頂点は残課題
- **ハッチング** — 境界検出とパターン生成
- **寸法記入** — 寸法スタイル、連動寸法
- ~~**ブロック**~~ — Issue #13 で「パラメトリックなコンポーネント」として再定義。
  段階 1（定義 + インスタンス）と段階 2（型付きパラメータと式）を実装済み。
  残るは段階 3（インプレース編集）と、操作のパネル化（Issue #15）
- **外部参照（XREF）** — 別ファイルの図面を参照する。
  コンポーネントの定義をファイル外に置く形になるので、
  定義テーブルの所有関係を作り直す必要がある
- **幾何拘束ソルバ**（一致・接線・直交・寸法拘束を解く / Fusion のスケッチ相当）
  — コンポーネントとは**直交した別問題**として独立させた（ADR-0028）。
  非線形連立方程式の反復解法、過小/過剰拘束の判定、数値的頑健性で数ヶ月規模。
  コンポーネントに抱き合わせると両方未完成で終わる
- **文字要素** — IME の動作検証（Phase 0）は済んでいるが、テキストエンティティ自体は未実装

## 3D

- 3D 機能全般

## 入出力

- **DWG 形式** — 仕様が非公開のため
- **印刷 / PDF 出力**
- DXF の R12 より新しいバージョン（R2000 以降）。
  **ネイティブ形式 `.ymc` の導入（Issue #11 / ADR-0026）で緊急度が下がった。**
  DXF は交換専用になったので、往復ロスは保存形式の問題ではなくなっている
- DXF の SPLINE / ELLIPSE / HATCH などの追加エンティティ
- **自動保存とクラッシュ復帰。** アトミック保存（ADR-0027）が守るのは
  「保存済みのファイルが壊れないこと」だけで、未保存の変更は守れない。
  退避先と間隔が設計の分岐なので、着手前にユーザーへ確認する
- ネイティブ形式の差分保存（速度が問題になってから）
