## 作図・編集

- **OFFSET** — 自己交差の処理が別問題として重い
  （`XLINE` の `O` オプションによる作図線のオフセットのみ実装済み）
- ~~**TRIM / EXTEND**~~ — Issue #7 段階 3 で実装。**線分のみ**。
  ポリラインの部分トリムは頂点列の再構成が必要なので残課題（ADR-0023）
- ~~**FILLET / CHAMFER**~~ — Issue #7 段階 3 で実装。**線分同士のみ**。
  円・円弧を含む角、ポリラインの頂点は残課題
- **ハッチング** — 境界検出とパターン生成
- **寸法記入** — 寸法スタイル、連動寸法
- **ブロック、外部参照**
- **文字要素** — IME の動作検証（Phase 0）は済んでいるが、テキストエンティティ自体は未実装
