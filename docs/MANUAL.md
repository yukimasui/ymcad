## コマンド

| コマンド | エイリアス | 内容 |
|---|---|---|
| LINE | `L` | 連続線分。Enter で終了、`C` でクローズ |
| CIRCLE | `C` | 中心 + 半径。オプション `D`（直径）、`2P`（2点） |
| ARC | `A` | 3 点指定 |
| RECTANGLE | `REC` | 対角 2 点 |
| POLYLINE | `PL` | 連結ポリライン |
| ERASE | `E` | 選択オブジェクト削除 |
| MOVE | `M` | 基点 + 目的点 |
| COPY | `CO` | 基点 + 目的点、複数回コピー継続 |
| STRETCH | `S` | 交差窓に入った点だけを移動（図形が変形する） |
| ROTATE | `RO` | 回転（基点 + 角度）。`C` で元を残す |
| SCALE | `SC` | 拡大縮小（基点 + 尺度）。`C` で元を残す |
| MIRROR | `MI` | 鏡像（対称軸の 2 点）。既定では元を残す |
| XLINE | `XL` | 無限長の作図線。`H`/`V`/`A`/`O` オプション |
| GROUP | `G` | 選択をグループ化 |
| UNGROUP | `UNG` | グループを解除 |
| EXPLODE | `X` | ポリラインを線分へ、コンポーネントのインスタンスを中身へ分解 |
| TRIM | `TR` | 線分を交点で切り取る。切断エッジの選択は不要 |
| EXTEND | `EX` | 線分を交点まで伸ばす。境界の選択は不要 |
| FILLET | `F` | 2 線分の角を丸める。`R` で半径 |
| CHAMFER | `CHA` | 2 線分の角を面取りする。`D` で距離 |
| COMPONENT | `B` / `BLOCK` | 選択をコンポーネント化（その場でインスタンスに置き換わる） |
| INSERT | `I` | コンポーネントを配置 |
| REDEFINE | `RD` | 定義の中身を差し替える（全インスタンスに反映） |
| PARAM | `PA` | コンポーネントにパラメータを宣言する |
| BIND | `BI` | コンポーネントの座標に式を束縛する |
| PSET | `PS` | インスタンスのパラメータを変える（`R` でリセット） |
| COMPONENTS | `CS` | **コンポーネントのパネルを開閉**（配置・パラメータ） |
| EDITCOMP | `BE` / `BEDIT` | コンポーネントをその場で編集する |
| ENDCOMP | `BC` | 編集を終えて定義へ書き戻す |
| UNDO | `U` | 元に戻す |
| REDO | — | やり直し |

## リボン（画面上端のアイコン）

コマンドは打つほかに、画面上端のリボンのアイコンを押しても始められます。

| タブ | グループ | ボタン |
|---|---|---|
| **ホーム**（起動時） | 作図 | LINE / POLYLINE / CIRCLE / ARC / RECTANGLE / XLINE |
| | 修正 | ERASE / MOVE / COPY / STRETCH / ROTATE / SCALE / MIRROR / TRIM / EXTEND / FILLET / CHAMFER / EXPLODE |
| | グループ | GROUP / UNGROUP |
| | 画層 | LAYER |
| **コンポーネント** | 定義・編集 | COMPONENT / REDEFINE / EDITCOMP / ENDCOMP |
| | 配置 | INSERT |
| | パラメータ | PARAM / BIND / PSET |
| | 一覧 | COMPONENTS |
| **表示・ファイル** | 表示 | ZOOM |
| | ファイル | NEW / OPEN / SAVEAS |
| タブの右隣（どのタブでも） | | UNDO / REDO / SAVE |

- **押すことは、そのコマンド名を打つのと同じです。** 履歴に `> LINE` が残り、プロンプトが出ます
  （動的入力がオンならカーソル横）。押したあとの空 `Enter` で同じコマンドを繰り返せます
- 押したあとも、そのまま座標やオプションを打てます（キーボードの入力先は変わりません）
- **コマンドの実行中に別のボタンを押すと、実行中のものを中断して**新しいコマンドを始めます
  （`Esc` と同じく選択も外れます）。何も実行していなければ選択は残るので、
  先に選んでから MOVE などを押せます
- ただし **LAYER と COMPONENTS（パネルを開閉するだけ）は中断しません。** 線を引いている途中で
  レイヤパネルを開いても、続きをそのまま描けます
- 日本語を変換している途中は、ボタンを押しても何も起きません。確定するか `Esc` で取り消してから押します
- 実行中のコマンドのボタンは色が付きます（打って始めたコマンドでも）。別のタブを開いているときは、
  そのコマンドがあるタブの名前に下線が付きます
- マウスを乗せると「名前 — 説明」と「打つ: エイリアス / 名前」が出ます。打つ名前を覚えるのにも使えます
- 窓の幅が足りないときは、端に「›」「‹」が出ます。押すか、リボンの上でマウスホイールを回すと
  横に送れます
- QUIT はリボンにありません（押し間違えで閉じないように）。✕ か `QUIT` を打ちます

アイコンの絵は `crates/cad-app/assets/icons/<コマンド名>.svg` です。差し替えてビルドし直すと
変わります（描き方の約束は同じフォルダの `README.md`）。

## キーバインド

### 実装済み

| キー / 操作 | 動作 |
|---|---|
| 中ボタンドラッグ | パン |
| ホイール | カーソル位置を中心にズーム |
| `Enter` / `Space` | コマンド確定（空なら直前のコマンドを再実行） |
| `Esc` | 実行中コマンドの中断、選択解除 |
| 左クリック | 点の指定 / オブジェクトのピック |
| 左→右ドラッグ | 窓選択（完全内包、青） |
| 右→左ドラッグ | 交差選択（交差を含む、緑の破線） |
| `Shift` + クリック / ドラッグ | 選択解除 |
| `F3` | オブジェクトスナップの ON/OFF（ステータスバーの `OSNAP` をクリックしても切り替わる） |
| `F8` | 直交モードの ON/OFF（水平・垂直に拘束）。ステータスバーの `ORTHO` をクリックしても切り替わる |
| `F10` | 極トラッキングの ON/OFF（15° 刻みに吸い付く）。ステータスバーの `POLAR` をクリックしても切り替わる |
| `F12` | 動的入力（カーソル横の入力欄）の ON/OFF。ステータスバーの `DYN` をクリックしても切り替わる |
| `↑` `↓` | コマンド候補の選択 |
| `Tab` | コマンド候補の補完。寸法入力の欄では値の固定と欄の移動 |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | 新規 / 開く / 上書き保存 |
| `Ctrl+Shift+S` | 名前を付けて保存 |

**キー入力は常にコマンドラインへ流れる**ので、入力欄をクリックする必要はありません。
`ZOOM`（`Z`）はコマンドとして実行し、`A`（全体）または `E`（範囲）を指定します。

### 動的入力（カーソル横の入力欄）

既定で ON。コマンドの実行中や文字を打っている間、**カーソルの右下**に
プロンプト・入力欄・コマンド候補が出ます。視線を画面下へ往復させずに済みます。

- **何もしていないときは何も出ません。** 最初の 1 文字を打った瞬間に現れます
- 画面の右端・下端では左側・上側へ回り込み、作図領域の外へははみ出しません。
  カーソルが作図領域の外（パネル・ステータスバー）に出ている間は最後の位置に留まります
- 日本語の変換中は位置が固定されます（候補ウィンドウが跳ねないように）
- エラーはカーソル横に 3 秒ほど赤で出ます。画面下の履歴には必ず残ります
- 画面下は**履歴と現在のプロンプト**だけになります
- 座標の解釈はコマンドラインと同じです（何も付けなければ絶対、`@` で相対）

`F12` またはステータスバーの `DYN` で OFF にすると、従来どおり画面下の入力欄に戻ります。

### 寸法入力（長さ・角度）と直接距離入力

LINE / PLINE の 2 点目以降と、MOVE / COPY / STRETCH の目的点では、
次の点を**直前の点（基点）からの長さと角度**で指定できます。

**直接距離入力**（動的入力の ON/OFF に関係なく使えます）

- 数値を 1 つだけ打って `Enter` … カーソルの**向き**に、その長さの点を置きます
  （カーソルまでの距離は関係ありません）。例: 線を右へ伸ばしたいならカーソルを右に置いて `100` `Enter`
- `1e3` のような指数表記は長さとして読みません（「座標を指定してください」になります）
- 動的入力が OFF のときの `Tab` は何もせず、「長さ・角度の固定は動的入力（F12）が
  オンのときに使えます」と案内します。打った値はそのまま残るので、`Enter` で直接距離入力になります
- カーソルが作図領域の外にある・基点と重なっていると、向きが決まらないのでエラーになります
- 長さが 0 以下はエラーになります

**長さ・角度の欄**（動的入力が ON のとき）

カーソル横に「長さ」「角度」の 2 欄が出ます。何も打っていない欄には、
基点からカーソルまでの長さと角度が薄く出て、マウスに合わせて変わります。

| 操作 | 動作 |
|---|---|
| 数字を打つ | 入力中の欄（最初は長さ）に入る |
| `Tab` | 打った値で今の欄を**固定**（🔒）して次の欄へ。何も打っていなければ固定せずに移るだけ。長さ ⇄ 角度 を巡回する |
| `Enter` | 固定した値と打った値で点を置く（打っていない欄はカーソルから決まる） |
| `Esc` | 固定と入力をすべて解除（`@10` のような数値以外の入力も消すだけ）。何も無ければコマンドを中断 |
| クリック | 固定した値に従った点が入る |

- **固定した値はラバーバンドにもクリックにも効きます。** 長さを固定すると向きだけが
  カーソルに付いてきます。角度を固定するとカーソルはその角度の線上に乗ります。
  両方固定すると点が 1 つに決まります
- 固定している間、スナップは「向き」や「射影の元」として効きます。そのため
  **スナップのマーカーとラバーバンドの先が離れて見えます**（長さを固定すればマーカーの方向に
  固定の長さ、角度を固定すればマーカーを固定の角度の線上へ射影した点が入ります）
- 角度だけ固定してカーソルを**その反対側**へ動かすと、長さが決まらないので
  ラバーバンドは基点に縮み、**クリックしても点は入らずエラーになります**（`Enter` も同じ）。
  固定は残るので、同じ側へ戻してクリックするか、長さも指定してください
- 角度は**度**で、+X 方向（右）から**反時計回り**です。直前の線分からの角度ではありません
  （`90` は常に真上、`-90` や `270` は真下）
- 例: 基点から真上に 100 … `100` `Tab` `90` `Enter`
- 点が入ると固定は外れ、長さの欄に戻ります
- `,` `@` `<` や英字を打つと欄は消え、いつもの入力欄に戻ります（`@50,20` や `C` は従来どおり）。
  その間は固定した値は効きません
- ROTATE（数値は角度）・SCALE（倍率）・CIRCLE（半径）などでは、数値の意味は変わりません

### 直交モード（F8）と極トラッキング（F10）

どちらも、**基準点（直前の点）からの向き**でカーソルを拘束する作図補助です。
起動時はどちらも OFF。ステータスバーの `ORTHO` / `POLAR` が大文字・明るい色なら ON、
小文字・薄い色なら OFF です（`OSNAP` / `DYN` と同じ）。

- **直交モード** … 基準点を通る水平線と垂直線のうち、カーソルに近い方へ点を乗せます。
  ちょうど 45° のときは水平になります
- **極トラッキング** … カーソルの向きが 15° の倍数（0°, 15°, 30°, 45°, …）から
  **±3° 以内**で、かつその線まで**画面上で 10px 以内**のとき、その線に吸い付きます。
  吸い付いている間は、吸い付いた点の先へ**水色の点線（補助線）**が伸び、カーソルの右上に
  `45°` のような**角度**が出ます。どちらかを外れているときはカーソルのままです
  （基準点のすぐ近くでも、角度が離れていれば自由な向きで引けます）
- 効くのは**点の指定を待っていて、基準点があるとき**だけです。LINE の 1 点目のように
  基準点が無いときは何もしません
- 基準点は、LINE / PLINE / MOVE / COPY / STRETCH では寸法入力と同じ基点、
  ROTATE / SCALE / MIRROR / CIRCLE / ARC / XLINE では直前に指定した点です。
  **RECTANGLE の対角には効きません**（水平・垂直にすると面積 0 の矩形になるため）
- ラバーバンドの先とクリックで入る点は常に同じです。直接距離入力（数値だけ打って `Enter`）の
  向きも拘束後の向きになります（例: 直交 ON で右寄りにカーソルを置いて `100` `Enter` → 右へ水平に 100）
- 寸法入力の欄のライブ値（長さ・角度）も拘束後の点から出ます
- MIRROR の「元のオブジェクトを消去しますか? [Y/N]」のように、点を指さない問い合わせの間は効きません
- **日本語の変換中は `F8` / `F10` で切り替わりません**（コマンドラインでもパネルの欄でも）。
  IME では `F8` が半角カナ、`F10` が半角英数への変換キーなので、そちらを優先します。
  変換中に切り替えたいときはステータスバーをクリックしてください

**2 つは独立したスイッチです。** 片方を切り替えても他方の状態は変わりません
（AutoCAD のように F8 で極トラッキングが勝手に切れることはありません）。
**両方 ON のときは直交が優先されます。** このとき `POLAR` は控えめの色になり、
極の補助線は出ません。直交を OFF にすると、そのまま極トラッキングが効きます
（履歴に「直交モード: OFF（極トラッキングが効きます）」と出ます）。

**優先順位**（上ほど強い）

| 順位 | 何が | どうなるか |
|---|---|---|
| 1 | 寸法入力の固定 | **角度を固定**していれば直交・極はかからず、固定の角度が使われます。**長さだけ固定**しているときは、向きを直交・極が決めます |
| 2 | オブジェクトスナップの吸着 | マーカーが出ているときは**吸着点がそのまま入ります**（直交・極はかかりません。AutoCAD と同じ）。直交 ON のままでも既存の図形の端点や交点へつなげられます |
| 3 | 直交モード | 水平・垂直 |
| 4 | 極トラッキング | 15° 刻みへの吸い付き |

スナップを優先しているので、直交 ON で「水平に引きたいのにスナップが吸い付いて斜めになる」
ときは、マーカーから離れた位置でクリックするか、`F3` でスナップを一時的に切ってください。

### コマンド候補

コマンド名を打ち始めると、先頭一致する候補が一覧で出ます。

- `Enter` … **`⏎` が付いている候補を実行する**。候補が出ていない場合だけ打った文字列を実行
- `↑` `↓` … 候補を選ぶ（選ぶと `⏎` がそちらへ移る）
- `Tab` … `⏎` の候補を入力欄へ補完する（補完した後もそのまま続けて打てる）
- `Esc` … 候補を閉じる（候補が出ていなければコマンドを中断）。
  **閉じた後の `Enter` は打った文字列のとおりに実行**します（`LIN` → `Esc` → `Enter` は
  「不明なコマンド」。見えていない候補は実行しない）。文字を打ち直すと候補はまた出ます

`⏎` は既定で先頭候補に付くので、**`L` と打って `Enter` で `LINE` が起動します**。
入力がコマンド名やエイリアスと完全一致する場合は、先頭でなくそちらが選ばれます
（`SAVE` は `SAVEAS` の接頭辞ですが、`SAVE` と打てば `SAVE` が走ります）。

日本語変換中は候補もキー操作も止まります。
レイヤ名などパネルの入力欄を編集している間も、`Enter` / `Space` / `Esc` は
その入力欄のもので、コマンドラインは受け取りません（編集を終えると戻ります）。

### XLINE（作図線）

無限に伸びる補助線です。オプションは AutoCAD 準拠にゃ。

```
XL → 2点          XL → H → 点（水平）      XL → V → 点（垂直）
XL → A → 角度 → 点                        XL → O → 距離 → 元の線 → 側
```

- **図面範囲（ZOOM EXTENTS）には影響しません。** AutoCAD と同じ扱いです
- DXF R12 に `XLINE` は無いため、保存すると**十分長い線分として書き出され、警告が出ます**
  （読み戻すと普通の線分になります）

### GROUP / UNGROUP / EXPLODE

- `GROUP`（`G`）… 選択した要素をまとめます。名前を省略すると連番の既定名が付きます。
  **グループの一員をクリックすると全体が選択されます**（AutoCAD の既定）
- `UNGROUP`（`UNG`）… 選択した要素が属するグループを解除します。要素そのものは残ります
- `EXPLODE`（`X`）… ポリラインを線分の集合に分解します。レイヤ・色・グループ所属を引き継ぎます

> DXF R12 に `GROUP` は無いため、保存するとグループ情報は失われ、警告が出ます。

### ROTATE / SCALE / MIRROR

```
RO → 基点 → 角度（度）        SC → 基点 → 尺度        MI → 軸の2点 → Y/N
```

- **角度は度**で入力します（座標入力の `@100<45` と同じ約束）。点で示すこともできます
- **尺度は 0 と負値を受け付けません。** 0 は図形が点に潰れ、負値は鏡像になるためです
  （反転したい場合は `MIRROR` を使ってください）
- `ROTATE` / `SCALE` の `C` オプションは元図形を残して複製を作ります
- `MIRROR` は最後に元を消すか聞きます。**既定は「残す」**（AutoCAD と同じ）で、
  `Enter` だけで残す方に倒れます

### TRIM / EXTEND

```
TR → 切り取る部分をクリック（何度でも）→ Enter
EX → 伸ばす側の端をクリック（何度でも）→ Enter
```

- **切断エッジ・境界は選びません。** 図面上の他のすべての図形が自動的にエッジになります
  （近年の AutoCAD のクイックモード相当）。いきなりクリックから始められます
- `TRIM` は**クリックした部分**が落ちます。両隣に交点があると線分が 2 本に分かれます
- `EXTEND` は**クリックした側の端**が、そちらの向きで最も近い交点まで伸びます
- 対象は**線分のみ**です。ポリラインは `EXPLODE`（`X`）で分解してから使ってください

### FILLET / CHAMFER

```
F   → R → 半径 → 1本目 → 2本目
CHA → D → 距離1 → 距離2 → 1本目 → 2本目
```

- **半径・距離はコマンドをまたいで記憶されます**（AutoCAD と同じ）。
  2 回目以降は `R` / `D` を省いて、いきなり線分をクリックできます
- **クリックした側が残ります。** 角のどちら側を残すかはクリック位置で決まります
- 対象は**線分同士のみ**です。円・円弧・ポリラインの頂点は対象外です
- 平行な 2 本や、交点が線分の延長上に無い場合はエラーになります

### コンポーネント

**定義を 1 つ作り、それを何度でも配置します。定義を編集すると全インスタンスが変わります。**

```
B  → 選択 → 基点 → 名前（Enter で既定名）
I  → 名前 → 位置 → 回転角（Enter で 0）→ 倍率（Enter で 1）
RD → 新しい中身を選択 → 基点 → 差し替えるコンポーネント名
X  → インスタンスを中身へ分解
```

- **`COMPONENT` は選択をその場でインスタンスに置き換えます。**
  AutoCAD の `BLOCK` は選択を消しますが、こちらは見た目が変わりません
  （Figma の「コンポーネント化」と同じ）
- **倍率は一様のみ。** X/Y 別倍率はありません。円が円のまま保たれます。
  反転したいときは `MIRROR` を使ってください
- 回転角は**度**で入力します（座標入力の `@100<45` と同じ約束）
- **入れ子にできます。** 循環（定義が自分自身を含む）は拒否されます
- インスタンスには `MOVE` / `COPY` / `ROTATE` / `SCALE` / `MIRROR` が効きます
- **インスタンス内部の端点・中点・中心・交点にスナップできます**
- `EXPLODE`（`X`）で分解すると、**中身が持っていたレイヤに戻ります**
  （AutoCAD と同じ）

### パラメータ（ダイナミックブロックの「アクション」の置き換え）

**型付きのパラメータを宣言し、座標に式を束縛します。**

#### 日常の操作はパネルから（打たなくていい）

`CS`（`COMPONENTS`）でパネルを開きます。

| したいこと | 操作 |
|---|---|
| 配置する | 定義の一覧から**「配置」ボタン** |
| 数値を変える | **ドラッグ**（範囲があればスライダ） |
| 真偽を切り替える | **チェックボックス** |
| 選択肢を変える | **ドロップダウン** |
| 既定値へ戻す | **「戻す」ボタン**（上書き中の項目にだけ出る） |
| パラメータを宣言する | **名前を打って型を選び「宣言」ボタン** |
| 宣言を消す | **「削除」ボタン** |

**同じコンポーネントのインスタンスを複数選べば、まとめて変えられます。**

いま効いている束縛も一覧で出ます（`LINE[0] の 終点X ← 幅` のような形）。
どの座標が何で動いているかが見えないと、式を直しようがないためです。

上書き中のパラメータは名前が**太字**になります。何が既定で何を変えたかが一目で分かります。

> **文字を打つのは名前を付けるときだけ**という方針にしています。
> 日本語入力を挟むと手が止まるので、値の変更はすべてマウスでできます。

#### 宣言と束縛（コマンドライン）

```
PA → 窓 → 幅 → 900              パラメータを宣言（型は既定値から決まる）
BI → 窓 → 0 → 終点X → 幅        線分の終点 X を「幅」で駆動
```

- **`BIND` は要素の番号とスロット名をプロンプトに出します。**
  定義の中身は図面に出ていないので、見ながら打てるようにしています
- 上書きしていない項目は定義の既定値を継承します（Figma と同じ）
- `PSET`（`PS`）はパネルを使わずに値を変えるコマンドラインの経路です

#### 式

```
四則        幅 / 2、高さ * 2 + 10
比較・論理  幅 > 500 && !両開き
条件        if 両開き then 幅 / 2 else 幅
関数        sin cos tan sqrt abs min max atan2 pow floor ceil round deg rad
```

- **識別子に日本語が使えます**（`幅`、`扉の向き`）
- **角度は度**です。ラジアンが要るときは `rad()` で明示的に変換します
- 既定値は他のパラメータを参照できます（`幅 = 高さ * 2 + 10`）。循環は拒否されます
- 0 除算・`sqrt(-1)`・`tan(90)` は**エラーで止まります**
  （`NaN` を座標へ流すと図形が消えて原因が追えなくなるため）

#### パラメータの型

| 型 | 宣言のしかた | 例 |
|---|---|---|
| 数値 | 既定値が数値になる式 | `900`、`高さ * 2` |
| 真偽 | `真` / `偽` | `偽` |
| 選択 | `|` で区切って並べる | `引違い\|開き\|FIX` |

#### インプレース編集

```
BE → インスタンスをクリック    定義の中身が実エンティティになる
（いつものコマンドで編集）      LINE / TRIM / MOVE …すべて使える
BC                             定義へ書き戻し、インスタンスへ戻る
```

編集中は **`BIND` がクリックで指せます**（番号もスロット名も打ちません）。

```
BI → 動かしたい点をクリック → X または Y → パラメータの番号
```

つまみ（端点・中心・半径・角度）のうち、**クリック位置に最も近いもの**が選ばれます。
軸は `X` / `Y`、パラメータは番号なので**すべて ASCII** です。式を打つこともできます。

- **画面上の見た目は変わりません。** 編集に入った瞬間に図形が飛ぶことがありません
- **編集の対象外は淡く表示されます。** モーダルにしないので、
  周りの図形を見ながら・スナップしながら編集できます
- 編集中に描いたものは定義に入り、消したものは定義から外れます
- **束縛は編集を通しても保たれます**（要素の順序が変わっても付いて回ります）
- 中身を全部消して終えようとすると断ります（空の定義は使い道がないため）

> DXF R12 には `BLOCK` / `INSERT` があるので書き出せますが、
> **パラメータは失われます**（保存時に警告が出ます）。

### STRETCH

交差選択（右→左ドラッグ）で囲んだ **点だけ** が動くので、図形の形が変わります。

```
S → 交差窓でドラッグ → Enter → 基点を指定 → 目的点を指定
```

- 線分は範囲に入った端点だけ、ポリラインは範囲に入った頂点だけが動きます
- 円と円弧は **中心** が範囲に入っていれば丸ごと動き、半径や角度は変わりません
- クリックや窓選択だけで選んだ場合は範囲が無いので、`MOVE` と同じく丸ごと動きます
- 交差窓は複数回重ねられます

### オブジェクトスナップ

点の入力を待っているときだけ有効になります。優先順位は
**端点 > 中点 > 中心 > 交点 > 垂線 > 最近点**。

| 種類 | マーカー |
|---|---|
| 端点 | 四角 |
| 中点 | 三角 |
| 中心 | 円 |
| 交点 | ✕ |
| 垂線 | 直角記号 |
| 最近点 | 砂時計 |

一度吸着すると、カーソルが多少動いても外れません（取得 10px / 解放 16px の
ヒステリシス）。半径は画面上の px で定義しているので、ズーム倍率によらず
操作感が一定です。

### 座標の直接入力

| 書式 | 意味 |
|---|---|
| `100,50` | 絶対座標 |
| `@100,50` | 直前の点からの相対座標 |
| `@100<45` | 直前の点からの相対極座標（長さ 100、角度 45°、反時計回り） |

IME のかな入力で全角になった `＠１００，５０` も自動で半角へ正規化して解釈します。
IME で変換中はコマンドラインの解釈を止めるため、未確定文字列がコマンドとして
実行されることはありません。

## ファイル形式

形式は 2 つあり、**役割が分かれています**。

| 形式 | 役割 | 往復 |
|---|---|---|
| **`.ymc`** | **ネイティブ。既定の保存形式** | **無損失** |
| `.dxf` | 交換用（他の CAD とのやりとり） | 非可逆。保存時に警告が出ます |

**形式は拡張子だけで決まります。** `.dxf` で開いたファイルの上書き保存は
`.dxf` のままです（勝手に別の形式へ移しません）。

保存は**アトミック**です。書き込み中にクラッシュや電源断が起きても、
保存前のファイルは失われません。

### `.ymc`（ネイティブ形式）

図面をそのまま保持するための自前バイナリ形式です。**往復して図面は変わりません。**
座標は `f64` のビット単位で保たれ、以下も含めてすべて保存されます。

- 作図線（`XLINE`）
- グループ所属
- 線種
- **コンポーネントの定義とインスタンス**（入れ子・反転・回転・倍率を含む）
- **日本語のレイヤ名・グループ名・コンポーネント名**（サニタイズされません）

> データベース（SQLite）は検討して却下しました。理由は
> [`DECISIONS.md`](DECISIONS.md) の ADR-0026 を参照してください。

### `.dxf`（交換用形式）

**DXF R12 (AC1009)** の読み書きに対応しています。

| 対応 | エンティティ |
|---|---|
| 書き出し | `LINE` / `CIRCLE` / `ARC` / `POLYLINE`(+`VERTEX`+`SEQEND`) |
| 読み込み | 上記 + `LWPOLYLINE` |

`LAYER` テーブル（名前・色・表示/非表示・ロック・線種）も入出力します。

**R12 で表現できないものは近似され、保存時に警告が出ます。**

| 落ちるもの | どうなるか |
|---|---|
| 作図線（`XLINE`） | 十分長い `LINE` になります |
| グループ | 情報が失われます |
| 線種 | `CONTINUOUS` 固定で書き出されます |
| レイヤ名・コンポーネント名 | 大文字化・空白除去されます |
| コンポーネントのパラメータ | 失われ、形が固定されます（`BLOCK` / `INSERT` 自体は書けます） |

> R12 には `LWPOLYLINE` が無いため、ポリラインは `POLYLINE` + `VERTEX` + `SEQEND` で
> 書き出します。読み込みは新しい形式の `LWPOLYLINE` も受け付けます。

未保存の変更がある状態で新規作成・開く・終了を行うと、保存の確認を挟みます。
