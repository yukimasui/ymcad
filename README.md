# ymcad

AutoCAD ライクな操作性を持つ **2D 専用** CAD アプリケーション。Rust + egui 製、Ubuntu ネイティブ。

> **状態: Phase 6 まで実装済み（全 Phase 完了）。**
> 進捗と次にやることは [`docs/PROGRESS.md`](docs/PROGRESS.md) を参照してください。

## ビルドと実行

### Ubuntu の依存パッケージ

```bash
sudo apt install build-essential pkg-config libssl-dev \
  libgtk-3-dev libxkbcommon-dev libwayland-dev
```

日本語 UI のためのフォントも必要です（未導入だと文字が □ になります）。

```bash
sudo apt install fonts-noto-cjk
```

### ビルド

```bash
cargo build --release
cargo run --release
```

### X11 で起動する

Wayland で不調な場合は X11 (XWayland) にフォールバックできます。

```bash
WAYLAND_DISPLAY= cargo run --release
```

> `WINIT_UNIX_BACKEND` は winit 0.30 で廃止されています。winit は `WAYLAND_DISPLAY` が
> 空なら `DISPLAY` を見て X11 を選ぶため、上記のように環境変数を空にして起動します。

| MIRROR | `MI` | 鏡像（対称軸の 2 点）。既定では元を残す |

| GROUP | `G` | 選択をグループ化 |

| EXPLODE | `X` | ポリラインを線分へ分解 |
| TRIM | `TR` | 線分を交点で切り取る。切断エッジの選択は不要 |
| EXTEND | `EX` | 線分を交点まで伸ばす。境界の選択は不要 |
| FILLET | `F` | 2 線分の角を丸める。`R` で半径 |
| CHAMFER | `CHA` | 2 線分の角を面取りする。`D` で距離 |
| COMPONENT | `B` / `BLOCK` | 選択をコンポーネント化（その場でインスタンスに置き換わる） |
| INSERT | `I` | コンポーネントを配置 |
| REDEFINE | `RD` | 定義の中身を差し替える（全インスタンスに反映） |

| BIND | `BI` | コンポーネントの座標に式を束縛する |
| PSET | `PS` | インスタンスのパラメータを変える（`R` でリセット） |
| COMPONENTS | `CS` | **コンポーネントのパネルを開閉**（配置・パラメータ） |
| UNDO | `U` | 元に戻す |

## キーバインド

### 実装済み

| キー / 操作 | 動作 |
|---|---|
| 中ボタンドラッグ | パン |
| ホイール | カーソル位置を中心にズーム |
| `Enter` / `Space` | コマンド確定（空なら直前のコマンドを再実行） |
| `Esc` | 実行中コマンドの中断、選択解除 |
| 左クリック | 点の指定 / オブジェクトのピック |
| 左→右ドラッグ | 窓選択（完全内包、青） |
| 右→左ドラッグ | 交差選択（交差を含む、緑の破線） |
| `Shift` + クリック / ドラッグ | 選択解除 |
| `F3` | オブジェクトスナップの ON/OFF |
| `↑` `↓` | コマンド候補の選択 |
| `Tab` | コマンド候補の補完 |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | 新規 / 開く / 上書き保存 |
| `Ctrl+Shift+S` | 名前を付けて保存 |

**キー入力は常にコマンドラインへ流れる**ので、入力欄をクリックする必要はありません。
`ZOOM`（`Z`）はコマンドとして実行し、`A`（全体）または `E`（範囲）を指定します。

### コマンド候補

コマンド名を打ち始めると、先頭一致する候補が一覧で出ます。

- `Enter` … **`⏎` が付いている候補を実行する**。候補が出ていない場合だけ打った文字列を実行
- `↑` `↓` … 候補を選ぶ（選ぶと `⏎` がそちらへ移る）
- `Tab` … `⏎` の候補を入力欄へ補完する
- `Esc` … 候補を閉じる（候補が出ていなければコマンドを中断）

`⏎` は既定で先頭候補に付くので、**`L` と打って `Enter` で `LINE` が起動します**。
入力がコマンド名やエイリアスと完全一致する場合は、先頭でなくそちらが選ばれます
（`SAVE` は `SAVEAS` の接頭辞ですが、`SAVE` と打てば `SAVE` が走ります）。

日本語変換中は候補もキー操作も止まります。

### XLINE（作図線）

無限に伸びる補助線です。オプションは AutoCAD 準拠にゃ。

```
XL → 2点          XL → H → 点（水平）      XL → V → 点（垂直）
XL → A → 角度 → 点                        XL → O → 距離 → 元の線 → 側
```

- **図面範囲（ZOOM EXTENTS）には影響しません。** AutoCAD と同じ扱いです
- DXF R12 に `XLINE` は無いため、保存すると**十分長い線分として書き出され、警告が出ます**
  （読み戻すと普通の線分になります）

### GROUP / UNGROUP / EXPLODE

- `GROUP`（`G`）… 選択した要素をまとめます。名前を省略すると連番の既定名が付きます。
  **グループの一員をクリックすると全体が選択されます**（AutoCAD の既定）
- `UNGROUP`（`UNG`）… 選択した要素が属するグループを解除します。要素そのものは残ります
- `EXPLODE`（`X`）… ポリラインを線分の集合に分解します。レイヤ・色・グループ所属を引き継ぎます

> DXF R12 に `GROUP` は無いため、保存するとグループ情報は失われ、警告が出ます。

### ROTATE / SCALE / MIRROR

```
RO → 基点 → 角度（度）        SC → 基点 → 尺度        MI → 軸の2点 → Y/N
```

- **角度は度**で入力します（座標入力の `@100<45` と同じ約束）。点で示すこともできます
- **尺度は 0 と負値を受け付けません。** 0 は図形が点に潰れ、負値は鏡像になるためです
  （反転したい場合は `MIRROR` を使ってください）
- `ROTATE` / `SCALE` の `C` オプションは元図形を残して複製を作ります
- `MIRROR` は最後に元を消すか聞きます。**既定は「残す」**（AutoCAD と同じ）で、
  `Enter` だけで残す方に倒れます

### TRIM / EXTEND

```
TR → 切り取る部分をクリック（何度でも）→ Enter
EX → 伸ばす側の端をクリック（何度でも）→ Enter
```

- **切断エッジ・境界は選びません。** 図面上の他のすべての図形が自動的にエッジになります
  （近年の AutoCAD のクイックモード相当）。いきなりクリックから始められます
- `TRIM` は**クリックした部分**が落ちます。両隣に交点があると線分が 2 本に分かれます
- `EXTEND` は**クリックした側の端**が、そちらの向きで最も近い交点まで伸びます
- 対象は**線分のみ**です。ポリラインは `EXPLODE`（`X`）で分解してから使ってください

### FILLET / CHAMFER

```
F   → R → 半径 → 1本目 → 2本目
CHA → D → 距離1 → 距離2 → 1本目 → 2本目
```

- **半径・距離はコマンドをまたいで記憶されます**（AutoCAD と同じ）。
  2 回目以降は `R` / `D` を省いて、いきなり線分をクリックできます
- **クリックした側が残ります。** 角のどちら側を残すかはクリック位置で決まります
- 対象は**線分同士のみ**です。円・円弧・ポリラインの頂点は対象外です
- 平行な 2 本や、交点が線分の延長上に無い場合はエラーになります

### コンポーネント

**定義を 1 つ作り、それを何度でも配置します。定義を編集すると全インスタンスが変わります。**

```
B  → 選択 → 基点 → 名前（Enter で既定名）
I  → 名前 → 位置 → 回転角（Enter で 0）→ 倍率（Enter で 1）
RD → 新しい中身を選択 → 基点 → 差し替えるコンポーネント名
X  → インスタンスを中身へ分解
```

- **`COMPONENT` は選択をその場でインスタンスに置き換えます。**
  AutoCAD の `BLOCK` は選択を消しますが、こちらは見た目が変わりません
  （Figma の「コンポーネント化」と同じ）
- **倍率は一様のみ。** X/Y 別倍率はありません。円が円のまま保たれます。
  反転したいときは `MIRROR` を使ってください
- 回転角は**度**で入力します（座標入力の `@100<45` と同じ約束）
- **入れ子にできます。** 循環（定義が自分自身を含む）は拒否されます
- インスタンスには `MOVE` / `COPY` / `ROTATE` / `SCALE` / `MIRROR` が効きます
- **インスタンス内部の端点・中点・中心・交点にスナップできます**
- `EXPLODE`（`X`）で分解すると、**中身が持っていたレイヤに戻ります**
  （AutoCAD と同じ）

### パラメータ（ダイナミックブロックの「アクション」の置き換え）

**型付きのパラメータを宣言し、座標に式を束縛します。**

#### 日常の操作はパネルから（打たなくていい）

`CS`（`COMPONENTS`）でパネルを開きます。

| したいこと | 操作 |
|---|---|
| 配置する | 定義の一覧から**「配置」ボタン** |
| 数値を変える | **ドラッグ**（範囲があればスライダ） |
| 真偽を切り替える | **チェックボックス** |
| 選択肢を変える | **ドロップダウン** |
| 既定値へ戻す | **「戻す」ボタン**（上書き中の項目にだけ出る） |

上書き中のパラメータは名前が**太字**になります。何が既定で何を変えたかが一目で分かります。

> **文字を打つのは名前を付けるときだけ**という方針にしています。
> 日本語入力を挟むと手が止まるので、値の変更はすべてマウスでできます。

#### 宣言と束縛（コマンドライン）

```
PA → 窓 → 幅 → 900              パラメータを宣言（型は既定値から決まる）
BI → 窓 → 0 → 終点X → 幅        線分の終点 X を「幅」で駆動
```

- **`BIND` は要素の番号とスロット名をプロンプトに出します。**
  定義の中身は図面に出ていないので、見ながら打てるようにしています
- 上書きしていない項目は定義の既定値を継承します（Figma と同じ）
- `PSET`（`PS`）はパネルを使わずに値を変えるコマンドラインの経路です

#### 式

```
四則        幅 / 2、高さ * 2 + 10
比較・論理  幅 > 500 && !両開き
条件        if 両開き then 幅 / 2 else 幅
関数        sin cos tan sqrt abs min max atan2 pow floor ceil round deg rad
```

- **識別子に日本語が使えます**（`幅`、`扉の向き`）
- **角度は度**です。ラジアンが要るときは `rad()` で明示的に変換します
- 既定値は他のパラメータを参照できます（`幅 = 高さ * 2 + 10`）。循環は拒否されます
- 0 除算・`sqrt(-1)`・`tan(90)` は**エラーで止まります**
  （`NaN` を座標へ流すと図形が消えて原因が追えなくなるため）

#### パラメータの型

| 型 | 宣言のしかた | 例 |
|---|---|---|
| 数値 | 既定値が数値になる式 | `900`、`高さ * 2` |
| 真偽 | `真` / `偽` | `偽` |
| 選択 | `|` で区切って並べる | `引違い\|開き\|FIX` |

> **インプレース編集（定義に入って編集する）は段階 3 です。**
> いまは `REDEFINE`（`RD`）で中身を差し替えます。

> DXF R12 には `BLOCK` / `INSERT` があるので書き出せますが、
> **パラメータは失われます**（保存時に警告が出ます）。

### STRETCH

交差選択（右→左ドラッグ）で囲んだ **点だけ** が動くので、図形の形が変わります。

```
S → 交差窓でドラッグ → Enter → 基点を指定 → 目的点を指定
```

- 線分は範囲に入った端点だけ、ポリラインは範囲に入った頂点だけが動きます
- 円と円弧は **中心** が範囲に入っていれば丸ごと動き、半径や角度は変わりません
- クリックや窓選択だけで選んだ場合は範囲が無いので、`MOVE` と同じく丸ごと動きます
- 交差窓は複数回重ねられます

### オブジェクトスナップ

点の入力を待っているときだけ有効になります。優先順位は
**端点 > 中点 > 中心 > 交点 > 垂線 > 最近点**。

| 種類 | マーカー |
|---|---|
| 端点 | 四角 |
| 中点 | 三角 |
| 中心 | 円 |
| 交点 | ✕ |
| 垂線 | 直角記号 |
| 最近点 | 砂時計 |

一度吸着すると、カーソルが多少動いても外れません（取得 10px / 解放 16px の
ヒステリシス）。半径は画面上の px で定義しているので、ズーム倍率によらず
操作感が一定です。

### 座標の直接入力

| 書式 | 意味 |
|---|---|
| `100,50` | 絶対座標 |
| `@100,50` | 直前の点からの相対座標 |
| `@100<45` | 直前の点からの相対極座標（長さ 100、角度 45°、反時計回り） |

IME のかな入力で全角になった `＠１００，５０` も自動で半角へ正規化して解釈します。
IME で変換中はコマンドラインの解釈を止めるため、未確定文字列がコマンドとして
実行されることはありません。

## ファイル形式

形式は 2 つあり、**役割が分かれています**。

| 形式 | 役割 | 往復 |
|---|---|---|
| **`.ymc`** | **ネイティブ。既定の保存形式** | **無損失** |
| `.dxf` | 交換用（他の CAD とのやりとり） | 非可逆。保存時に警告が出ます |

**形式は拡張子だけで決まります。** `.dxf` で開いたファイルの上書き保存は
`.dxf` のままです（勝手に別の形式へ移しません）。

保存は**アトミック**です。書き込み中にクラッシュや電源断が起きても、
保存前のファイルは失われません。

### `.ymc`（ネイティブ形式）

図面をそのまま保持するための自前バイナリ形式です。**往復して図面は変わりません。**
座標は `f64` のビット単位で保たれ、以下も含めてすべて保存されます。

- 作図線（`XLINE`）
- グループ所属
- 線種
- **コンポーネントの定義とインスタンス**（入れ子・反転・回転・倍率を含む）
- **日本語のレイヤ名・グループ名・コンポーネント名**（サニタイズされません）

> データベース（SQLite）は検討して却下しました。理由は
> [`docs/DECISIONS.md`](docs/DECISIONS.md) の ADR-0026 を参照してください。

### `.dxf`（交換用形式）

**DXF R12 (AC1009)** の読み書きに対応しています。

| 対応 | エンティティ |
|---|---|
| 書き出し | `LINE` / `CIRCLE` / `ARC` / `POLYLINE`(+`VERTEX`+`SEQEND`) |
| 読み込み | 上記 + `LWPOLYLINE` |

`LAYER` テーブル（名前・色・表示/非表示・ロック・線種）も入出力します。

**R12 で表現できないものは近似され、保存時に警告が出ます。**

| 落ちるもの | どうなるか |
|---|---|
| 作図線（`XLINE`） | 十分長い `LINE` になります |
| グループ | 情報が失われます |
| 線種 | `CONTINUOUS` 固定で書き出されます |
| レイヤ名・コンポーネント名 | 大文字化・空白除去されます |
| コンポーネントのパラメータ | 失われ、形が固定されます（`BLOCK` / `INSERT` 自体は書けます） |

> R12 には `LWPOLYLINE` が無いため、ポリラインは `POLYLINE` + `VERTEX` + `SEQEND` で
> 書き出します。読み込みは新しい形式の `LWPOLYLINE` も受け付けます。

未保存の変更がある状態で新規作成・開く・終了を行うと、保存の確認を挟みます。

## 構成

```
crates/
├── cad-core/   ジオメトリ・エンティティ・コマンド・ファイル入出力（UI 非依存）
└── cad-app/    egui アプリケーション（入力処理・描画）
```

`cad-core` は egui / eframe / winit に依存しません（将来 wasm ビューアを載せる余地を残すため）。
この不変条件は CI で機械的に検査しています。

設計の詳細は [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)、
判断の経緯は [`docs/DECISIONS.md`](docs/DECISIONS.md) を参照してください。

## 開発

```bash
cargo fmt --all
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

書き出したファイルは **Rust とは別ロジック**でも検査します。
ラウンドトリップテストは「自分で書いて自分で読む」ため、書き手と読み手が同じ誤解を
していれば往復が成立してしまい、書き出しのバグを見逃します。

```bash
cargo run -p cad-core --example write_sample -- /tmp/sample.ymc
python3 tools/validate_ymc.py /tmp/sample.ymc --verbose

cargo run -p cad-core --example write_sample -- /tmp/sample.dxf
python3 tools/validate_dxf_r12.py /tmp/sample.dxf
```

どちらも CI で自動的に走ります。
