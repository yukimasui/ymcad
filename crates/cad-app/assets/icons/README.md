# リボンのアイコン

リボン（画面上端のタブつきアイコンバー）のボタンの絵。**1 コマンド 1 ファイル**で、
ファイル名はコマンド表の正式名（`LINE.svg`、`SAVEAS.svg` …）。

ビルド時に `include_bytes!` で実行ファイルへ埋め込む（`crates/cad-app/src/ribbon/icons.rs`）。
**ファイルを差し替えてビルドし直すだけで絵が変わる。** コードを触る必要は無い。

## 描き方の約束

| 項目 | 約束 | 理由 |
|---|---|---|
| 大きさ | `viewBox="0 0 24 24"`（`width`/`height` も 24） | 表示は 22px 前後。2 倍でも崩れないよう線は太すぎず細すぎず |
| 色 | **白一色（`#ffffff`）**。塗りも線も | 表示側で `tint`（乗算）して色を付ける。通常は文字色、実行中のボタンは選択色。白以外の色はその部分だけ着色されない |
| 補助線 | 白のまま不透明度を下げる（`stroke-opacity="0.45"` / `fill-opacity`） | 元の形・消える部分・寸法補助線など。乗算なので、どの色でも「薄い同じ色」になる |
| 線幅 | `1.5` にそろえる（強調したい柄などは 3） | 全アイコンで太さがそろって見える |
| 端と角 | `stroke-linecap="round"`、`stroke-linejoin="round"`（破線は `butt`） | |
| 破線 | `stroke-dasharray="2 1.5"` | |
| 余白 | 線の外側が 0〜24 からはみ出さないように | はみ出した部分は切れる |
| 文字 | **使わない**（`<text>`） | 文字の描画機能（`svg_text`）を入れていないので出ない。形で描く |
| その他 | フィルタ・グラデーション・外部参照・埋め込み画像は使わない | 外部のツールで描いた SVG でもそのまま読めるよう、基本の図形だけにする |

Inkscape などで描いた SVG は `style="fill:…;stroke:…"` の形で色を書くことがある。
それでもよいが、色は白か `none` にすること。

## テストが確かめていること（`cargo test -p cad-app ribbon`）

- リボンに置いた全コマンドに SVG がある
- このフォルダに、対応するコマンドの無い余分なファイルが無い（この README を除く）
- 全 SVG が `usvg`（表示に使うライブラリ）で読め、24×24 で何かが描かれる
- 色の指定が白（か `none`）だけ

アイコンを足すとき（コマンドをリボンに足したとき）は、SVG を置いたうえで
`ribbon/icons.rs` の表 `ICONS` に 1 行足す。

## 見た目の確認

```bash
cargo test -p cad-app -- --ignored ui_snapshot_ribbon_icon_sheet
```

`target/ui-snapshots/ribbon_icon_sheet.png`（暗いテーマ）と `ribbon_icon_sheet_light.png`
（明るいテーマ）に、全アイコンを 2 倍・等倍・実行中の強調の 3 通りで名前つきの格子に並べて撮る。
