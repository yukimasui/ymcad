2. 調査した世間の不満と対策

AutoCAD Dynamic Input への不満ymcad での対策
2 点目以降に打った座標が勝手に相対扱いになり、線が変な位置に引かれる（絶対には # が要る）既定は絶対のまま。長さ・角度は名前つきの欄で入れる（段階 B）
密集した図面で図形やスナップを覆うカーソルの右下にずらし、半透明で出す。画面端では反対側へ回り込む
案内やエラーを見逃す・履歴が追えないエラーはカーソル横にも数秒出し、画面下の履歴にも必ず残す
慣れた人にはうるさい何もしていないときは出さない。F12 とステータスバーでオン/オフ
Tab で長さ・角度を固定する操作が分かりにくい入力中の欄を強調し、固定した欄には錠前マーク（段階 B）
マルチモニタで表示が張り付く位置は毎フレーム計算し、キャンバスの中に収める

3. 着手前の試作

3-1. 画面を自動で撮る仕組み ✅ 成功

egui_kittest をテスト用の依存として cad-app に追加。アプリを画面に出さずに、マウス移動とキー入力を流し込んで PNG に撮れることを確認した（環境変数の指定は不要、撮影 1 回あたり約 2〜5 秒）。cad-core には何も足していない。以後の見た目の確認はこれで行う。
